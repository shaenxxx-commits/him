# docs/KNOWLEDGE_STATES.md

Модель состояний знания HIM (двумерная). Одно утверждение может иметь и эпистемический статус, и тип.

Связанные инварианты: I3 (статусы знания), I8 (гипотезы), I19 (внешние).
Статусы маркируются как в `INVARIANTS.md` I3.

## 1. Эпистемический статус

- **UNKNOWN** — явно обозначенный пробел. Не заполняется предположениями.
- **HYPOTHESIS** — проверяемое объяснение. Требует процедуры проверки (I8).
- **SUPPORTED** — есть подтверждающие данные, нет полной верификации.
- **VERIFIED** — подтверждено установленной процедурой или источником.

## 2. Тип утверждения

- **OBSERVATION** — непосредственно зафиксированное наблюдение.
- **RESULT** — результат выполненной процедуры (проверка, измерение, действие).
- **INTERPRETATION** — объяснение значения наблюдения или результата.

**FACT не является типом.** `FACT` — метка статуса `VERIFIED` (§4). Тип — что это; статус — насколько подтверждено.

## 3. Правила

- Одно утверждение может иметь и статус, и тип.
- Переход статуса фиксируется в `meta/transitions.md` (основной рабочий инструмент).
- `INTERPRETATION` не становится `VERIFIED` автоматически.
- `RESULT` не является автоматически `VERIFIED`.
- Повышение статуса — только при наличии источника и фиксации перехода (I3).

## 4. Компактные маркировки

| Маркировка | Значение | Соответствие |
|---|---|---|
| `[ФАКТ]` | VERIFIED, источник назван | VERIFIED × (OBSERVATION/RESULT) |
| `[ПОДТВЕРЖДЕНО]` | SUPPORTED, проверка неполная | SUPPORTED × (OBSERVATION/RESULT) |
| `[ГИПОТЕЗА]` | Предположение | HYPOTHESIS × (любой тип) |
| `[НЕИЗВЕСТНО]` | Данных нет | UNKNOWN |
| `[МОЯ ПОЗИЦИЯ]` | Позиция агента, не факт | вне модели |
| `[ВНЕШНИЙ — <имя>]` | Дословный вывод внешнего | внешний источник (I19) |

**`[ФАКТ]` — только для VERIFIED.** Неполная проверка → `[ПОДТВЕРЖДЕНО]`.

## 5. Что не допускается

- Автоматическое повышение статуса (I3).
- Заполнение `UNKNOWN` предположением.
- Использование `[МОЯ ПОЗИЦИЯ]` для маскировки внешнего мнения.
- Восстановление дословного текста внешнего по памяти (I3).
- Использование `[ФАКТ]` для SUPPORTED.

## 6. Связь с провенансом

SUPPORTED / VERIFIED / RESULT должны иметь прослеживаемый источник (I4). До подключения `PROVENANCE.md` запись фиксирует: утверждение, статус, тип, источник, процедуру, результат, ограничения.
