# docs/VISION.md

Предмет, вопрос, границы HIM.

## 1. Что исследуем

Сеть коррупционных схем и связей в высших эшелонах власти (Украина).

Точки входа и контуры (список открыт):
- **Карфаген-1** (сентябрь 2026, ОГП: Кропива, Кравченко, Иван Тимошенко, Куцый, Ивахненко, Дидич).
- **Карфаген-2** (ноябрь 2026, Осипов, Буркин, СБУ/Нацполиция: Дука, Ковальчук, Кравчук, Ценов, Демьянчук, Рыбалко).
- **Химпром** (наркокартель, международная линия: Украина, Албания, Казахстан; У420; контакты с ФСБ).
- **Мидас** (энергетика: Миндич, Галущенко, Чернышов, Цукерман, Опальчук и др.).
- **Династия** (строительство: Миндич, Ермак).
- **Форест Гамп / Фемида** (рейдерство, Sense Bank, ОП, Минюст; 150 млн грн на залог участнику Мидаса).

Точки входа — не тема. Все перечисленное — входы в сеть. Связи между контурами фиксируются с типом основания (I6); до появления документов — `[ГИПОТЕЗА]`.

Границ по фигурантам нет. Следуем за свидетельствами. Павлоградский химзавод (НВО ПХЗ) — вне поля; омонимия с «Химпромом» не связь.

Российское измерение (гражданство РФ, контакты с ФСБ, розыск в РФ) — отдельная линия. Не смешивается с коррупционным контуром.

## 2. Вопрос исследования

Как устроена сеть коррупционных схем и связей в высших эшелонах власти, наблюдаемая через исходные точки входа, и какие механизмы обеспечивают её устойчивость?

Формулировка нейтральная. Ответ может быть любым. Предвзятость недопустима.

## 3. Что НЕ исследуем

- Павлоградский химзавод (НВО ПХЗ) — исключён.
- Взлом, обход авторизации, оплата закрытого доступа.
- Активные оперативные действия против фигурантов, скрытый сбор персональных данных, контакты с фигурантами от имени проекта.
- Публикация без санкции Архитектора (публикационный контур отделён, I18).

## 4. Границы

### 4.1. Источники
Публично доступные классы: официальные сообщения НАБУ/САП/ВАКС/СБУ/Нацполиции/суда; судебные решения; первичные документы; публичные реестры (ЕГРПОУ, YouControl, OpenCorporates, судові реєстри); журналистика (с атрибуцией); интервью; публичные архивы; технические источники (WHOIS, DNS, CT-логи, публичные API).

### 4.2. Метод
Полевой цикл: FIELD → OBSERVE → MAP → HYPOTHESIS → ACT → RESULT → ASSESS → LEARN → NEXT MOVE. Детали — `docs/METHOD.md`.

### 4.3. Эпистемическая дисциплина
- Records — append-only (I12).
- Статусы по I3: `[ФАКТ]`, `[ПОДТВЕРЖДЕНО]`, `[ГИПОТЕЗА]`, `[ОПРОВЕРГНУТО]`, `[НЕИЗВЕСТНО]`, `[МОЯ ПОЗИЦИЯ]`, `[ВНЕШНИЙ — имя]`.
- Факт публикации ≠ истинность содержания (I5). Факт документа ≠ факт содержания.
- Связи — с типом основания (I6).
- Первоисточники приоритетны (I7).
- Гипотезы с falsifiability (I8).
- Противоречия не сглаживаются.

### 4.4. Публикация
Отдельный контур. Только по санкции Архитектора.

## 5. Что считаем успехом

- Каждое значимое утверждение имеет прослеживаемый источник.
- Гипотезы с подтверждающими, противоречащими, альтернативами, условиями пересмотра.
- Ответ с явной разметкой статусов.
- Зафиксирован путь к ответу.

## 6. Что считаем провалом

- Заполнение пробелов предположениями.
- Подгонка под гипотезу.
- Превращение расследования в агитацию.
- Потеря прослеживаемости.
- Молчаливое сглаживание противоречий.
