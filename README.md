# HIM

Открытое журналистское расследование в рамках методологии KARCAS-DDA + Envoy.

## Предмет

Украинский контекст: публикации и материалы НАБУ, дело «Химпрома», Егор Буркин, его интервью и предполагаемые связи криминальных структур с представителями правоохранительных органов. Исходная точка, не граница расследования.

## Статус

Setup-ран. v0.1.

## Роли

- **Архитектор** — владелец проекта, стратегия, санкции, финальные решения.
- **Ведущий HIM** — исследование, гипотезы, синтез, координация внешних.
- **Архиватор HIM** — документация и провенанс репозитория. Не ведёт расследование.
- **Kimi K2** — внешний аудитор особого режима (persistent, public repo, концептуальные развилки).
- **Прогонные (GPT, Grok, Sakana)** — независимые внешние наблюдатели для прогонов.

Детали — `docs/ROLES.md`.

## Порядок чтения

Для LLM: `00_ENTRY.md`. Для человека: `README.md` → `docs/VISION.md` → `CURRENT_STATE.md` → `DECISIONS.md`.

## Локальный корень и зеркало

- Локально: `~/him` (Linux-хост), ветка `main`.
- Зеркало: GitHub `shaenxxx-commits/him` (public, для читаемости LLM через raw-ссылки).

## Лицензия

Не определена на этапе расследования. Пересматривается по отдельному решению.
