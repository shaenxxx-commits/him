# HIM

Открытое журналистское расследование: коррупционные схемы и связи в высших эшелонах власти (Украина).

## Предмет

Точки входа: «Карфаген», «Химпром», «Мидас», «Династия», Буркин, Миндич, Ермак. Границ по фигурантам нет. Детали — `docs/VISION.md`.

## Роли

- **Архитектор** — владелец, стратегия, санкции, финальные решения.
- **Ведущий HIM** (DeepSeek) — исследование, гипотезы, синтез, координация внешних.
- **Архиватор HIM** (DeepSeek, отдельный чат) — документация и провенанс. Расследование не ведёт.
- **Kimi K2** — внешний аудитор особого режима (persistent, public repo, сложные развилки).
- **Прогонные (GPT, Grok, Sakana)** — независимые внешние наблюдатели, clean init.

Запрещённые подмены: Архитектор ≠ Ведущий, Ведущий ≠ Внешний, Внешний ≠ Архитектор, Архиватор ≠ Ведущий.

## Порядок чтения

Для LLM: `INVARIANTS.md` → `CURRENT_STATE.md` → `DECISIONS.md` (accepted) → `docs/VISION.md` → `docs/METHOD.md`.
