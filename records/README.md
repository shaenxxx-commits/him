# records/ — первичные записи HIM

Append-only. Исправления — новой записью (I12). Устаревшее — в `ARCHIVE/`.

## Формат записи
FIELD / DATE / OBSERVER / OBSERVATION / SOURCE / ACTION / RESULT / INTERPRETATION /
HYPOTHESIS / UNKNOWN / NEXT STEP.

## Именование
`NNN-slug.md`, NNN — тризначный сквозной.

## Маркировка
По I3: [ФАКТ], [ПОДТВЕРЖДЕНО], [ГИПОТЕЗА], [ОПРОВЕРГНУТО], [НЕИЗВЕСТНО],
[МОЯ ПОЗИЦИЯ], [ВНЕШНИЙ — <имя>]. Флаг [ЗАИНТЕРЕСОВАННАЯ СТОРОНА] для заявлений
фигурантов.

## Провенанс
SOURCE — точное (URL с датой доступа / файл / SHA / документ). Raw > ~20 КБ — вне git
(`~/raw-external/him/`), в записи: путь, размер, sha256, дата.

## Связь с реестрами
- Решение — `D-YYYYMMDD-XX`.
- Переход статуса — `meta/transitions.md`.
- Фигурант — `records/figurants.md`.
- Связь — `records/links.md` с типом основания (I6).
- Гипотеза — `records/hypotheses.md`.

## Шаблоны (слито из templates/README)

Решение (D): статус / дата / утверждающий / контекст / решение / основание /
последствия / условие пересмотра / связанные / заменяет.

Гипотеза: H-NNN — формулировка / основание / подтверждающие / противоречащие /
альтернативы / неизвестно / проверка / статус / условие пересмотра.

Связь: L-NNN / от / к / тип (I6) / основание / статус / дата.

Задание внешнему: от / кому / тема / вход / задача / формат ответа / ограничения /
не делать.

Lead synthesis: run / дата / входы / консенсус / расхождения / уникальное / беру /
откладываю / отклоняю / Архитектору.

## Минимальность
Один полный запись лучше десяти пустых (I17).
