# records/ — первичные записи HIM

Append-only. Исправления — новой записью с причиной (I12). Устаревшее — в `ARCHIVE/`.

## Формат записи

    FIELD:          <эпизод / тема / контекст>
    DATE:           <YYYY-MM-DD из date>
    OBSERVER:       <ведущий / модель / человек>
    OBSERVATION:    <что зафиксировано, со статусом>
    SOURCE:         <URL с датой доступа / файл / SHA / документ>
    ACTION:         <что сделано для получения>
    RESULT:         <что получено>
    INTERPRETATION: <значение, со статусом>
    HYPOTHESIS:     <гипотезы, со статусом>
    UNKNOWN:        <что осталось неизвестным>
    NEXT STEP:      <следующее действие или решение>

## Именование

`NNN-slug.md`, NNN — тризначный сквозной, не сбрасывается.

## Маркировка

Каждое утверждение в OBSERVATION / INTERPRETATION / HYPOTHESIS — со статусом по `docs/KNOWLEDGE_STATES.md`.

## Провенанс

SOURCE — точное. Raw > ~20 КБ — вне git (`~/raw-external/him/`), в записи: путь, размер, sha256, дата. Реконструкция по памяти запрещена (I3).

## Связь с реестрами

- Приводит к решению — ссылка на `D-YYYYMMDD-XX`.
- Переход статуса — ссылка на `meta/transitions.md`.
- Фигурант — ссылка на `records/figurants.md`.
- Связь между лицами — `records/links.md` с типом основания (I6).

## Минимальность

Один полный запись лучше десяти пустых (I17).
