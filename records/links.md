# records/links.md

Граф связей между узлами (люди, организации, события, документы). Append-only.
Формат записи — см. `templates/README.md` (раздел «Связь»).

Типы связи:
- документально установлена;
- прямое заявление источника;
- косвенное свидетельство;
- аналитически предполагаемая;
- неподтверждённая гипотеза.

Упоминание двух лиц в одном документе — не связь (I6).
