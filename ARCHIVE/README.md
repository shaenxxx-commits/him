# ARCHIVE/

Устаревшее. Не удаляется (I12), переносится сюда с датой и причиной.

## Формат

Имя файла: `<оригинальное-имя>.archived-YYYY-MM-DD.md`
В начале файла:

    ARCHIVED: YYYY-MM-DD
    REASON: <причина>
    SUPERSEDED BY: <ссылка на актуальный документ / решение>

## Что не архивируется

- Решения (`DECISIONS.md`) — append-only, старая запись остаётся.
- Записи `records/` — append-only, исправления новой записью.
